# 🥚 RasPI Tamagochi
**Work in progress 🚧**

A little Raspberry Pi companion designed to help you learn and practice **Chinese vocabulary (HSK 4–5)**.

The Tamagochi asks you questions about Chinese characters and words, helping you practice both their **meaning** and **pronunciation** in a fun and interactive way.


## 🧠 How it works

The Tamagochi presents a Chinese character or word and asks you to:

* 🇨🇳 Identify its **meaning**
* 🔊 Provide its **pronunciation**
* 📝 Practice HSK 4–5 vocabulary
* ⭐ Keep track of your progress with STAR points

The exact interaction will depend on the hardware and software developed for the project.

## 🛠️ Technologies

This project is built around a **Raspberry Pi 5** and will involve:

* Raspberry Pi
* Python
* Chinese HSK 4–5 vocabulary
* Display / user interface
* Input controls
* Audio / pronunciation
* Electronics and sensors *(depending on the final design)*
